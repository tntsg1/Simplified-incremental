# 城市暂停、设置和武器入口

2026-10-24。更正前一版误把武器集中进设置的改动。

## Esc 第一层

三个主要按钮：继续、设置、退出。继续恢复战斗；设置进入普通偏好页；退出保存进度并退出游戏。打开暂停或设置期间，战斗和 Boss 倒计时停止。

## 设置子页

只包含声音开关、音乐音量、音效音量、语言、画面效果、镜头、文字提示等普通选项。开发版本中也可切换开发者模式。这里不列出导弹发射井或任何炮台，不显示单发、三连发、重点拦截或分路拦截选项。

Esc 从设置返回第一层，再按 Esc 继续战斗。

## 开发者模式的直接入口

原有 `~` 快捷键保留：直接开启或关闭开发工具栏。在 Esc 第一层，开发模式开启后也直接显示资金、跳波等测试操作，无需进入设置子页。原有开发权限不变。

## 武器各自的入口

- 点击导弹发射井，才在模型旁打开这座发射井的小卡片；与其他炮台同宽、同边框、同关闭方式，不遮黑画面、不暂停战斗；第一至第五波只显示基础信息，第六波才显示重点／分路拦截按钮和说明，没有提前显示的灰色锁定项。
- 点击哪座已改造炮台，就只显示那座炮台的详情与单发／三连发配置。
- 点击未改造建筑，仍打开它自己的改造卡，保留原价格和购买规则。
- 炮台之间、炮台与主导弹之间的设置互不修改。其他章节保留原攻击和原详情卡。
- Boss 裂隙继续直接点击和跟瞄，不恢复目标选择框。文字提示的偏好仍在普通设置里。
